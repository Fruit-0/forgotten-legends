# 项目记忆索引

## 用户背景（跨项目通用）

### 技术背景

- **主力语言**: Java，企业级应用开发背景
- **软件工程理念**: 关注点分离（Separation of Concerns）、整洁架构
- **期望视角**: Claude 站在"使用者视角"而非"实现者视角"提供方案
- **短板1**: 没有美术基础, 无法自行设计出美观的界面和界面,需要对应的角色协助设计
- **短板2**: 没有游戏开发经验。

### 核心协作原则

1. **关注点分离** - 工具与产出物严格分离，项目保持纯净
2. **需求确认原则** - 不擅自替用户做需求决策，模糊时主动澄清
3. **最小化设计** - 删除非必需优于保留可能有用
