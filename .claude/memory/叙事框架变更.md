# 叙事框架变更记录

## 变更日期

2026-03-31

## 变更前

**框架**: 被遗忘的传说
- 情感核心：存在主义的觉醒
- 主角身份：书中角色
- 世界性质：古老故事书
- 结局类型：觉醒（超越叙事）
- 文化底色：欧式童话忧伤

## 变更后

**框架**: 当时只道是平常
- 情感核心：回归平凡的感动
- 主角身份：现代大学生（刚参加工作的社畜）
- 世界性质：游戏化西幻
- 结局类型：回家（拥抱日常）
- 文化底色：中式家庭温情

## 变更原因

用户明确选择更符合个人情感共鸣的中式温情叙事，强调"平凡日常的可贵"这一主题。

## 受影响的系统

1. **主角设定**: 现代大学生穿越，拥有游戏化属性面板
2. **技能系统**: 明确水/火/风/土元素魔法体系
3. **UI风格**: 可融入现代元素（手机界面风格）
4. **情绪曲线**: 迷茫→孤独→温暖→释然→感动
5. **结局设计**: 必须包含"妈，我回来了"场景
