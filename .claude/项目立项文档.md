# 项目立项文档

## 基础信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 我在异世界的那些年 |
| 类型 | 2D俯视角动作RPG |
| 引擎 | Godot 4.6 + GDScript |
| 目标平台 | Windows PC |
| 目标分辨率 | 1920x1080，像素画风格（建议16x16或32x32基础图块） |
| 游戏时长 | 2小时 |
| 参考游戏 | 奈斯启示录（Necesse） |

## 核心体验

**一句话描述**：在像素风格的章节地图中探索、战斗、成长，最终击败Boss通关。

**核心循环**：
```
探索地图 → 击败敌人/完成任务 → 获取装备/材料/技能点 → 变强 → 挑战Boss → 进入下一章
```

## 游戏系统概要

### 战斗系统
- **类型**：即时动作（非回合制）
- **操作**：WASD移动，鼠标瞄准攻击，空格闪避
- **死亡惩罚**：无惩罚，在当前区域复活
- **存档**：随时存档（F5快速存档，F9快速读档）

### 成长系统
- **装备获取**：敌人掉落 + 材料合成 + 商店购买 + 任务奖励
- **技能学习**：消耗技能点解锁（技能点来自升级和任务）
- **属性提升**：随等级自动成长

### 经济系统
- **双货币**：
  - 金币：通用货币，用于商店购买
  - 材料：用于合成装备，分为普通/稀有/传说品质

### 世界结构
- **章节式**：共3-4个章节，每个章节一张固定设计的小地图
- **地图规模**：每张地图预计5-10分钟探索时间
- **连接方式**：击败章节Boss后解锁下一章传送门

## 内容规划

### 章节设计

| 章节 | 主题 | 地图规模 | 敌人种类 | Boss |
|------|------|----------|----------|------|
| 第一章 | 森林外围 | 小型 | 2种 | 哥布林王 |
| 第二章 | 地下洞穴 | 中型 | 3种 | 巨型蜘蛛 |
| 第三章 | 古代遗迹 | 中型 | 4种 | 守护者 |
| 终章 | 深渊入口 | 小型 | 5种 | 深渊领主 |

### 装备规划

| 类型 | 数量 | 获取方式 |
|------|------|----------|
| 武器 | 8-10把 | 掉落/合成/购买 |
| 防具 | 3套 | 掉落/合成 |
| 饰品 | 4-5个 | 任务/隐藏宝箱 |

### 技能规划

| 类型 | 数量 | 示例 |
|------|------|------|
| 主动技能 | 4-5个 | 旋风斩、冲刺攻击、远程剑气 |
| 被动技能 | 6-8个 | 攻击力+10%、移动速度+15% |

## 技术约束

- **最大同屏敌人**：不超过8个（保证性能）
- **输入方式**：键鼠（暂不支持手柄）
- **本地化**：仅简体中文（首期）
- **分辨率自适应**：支持16:9和16:10

## 开发里程碑

### Phase 1：核心玩法原型（第1-2周）
- [ ] 玩家移动、攻击、闪避
- [ ] 1种近战敌人AI
- [ ] 简单的伤害计算
- [ ] 一个测试用的小型地图

### Phase 2：战斗系统完善（第3-4周）
- [ ] 敌人受击/死亡反馈（闪白、击退）

- [ ] 2种不同攻击模式的敌人
- [ ] 碰撞检测优化

## 风险评估

| 风险 | 等级 | 应对措施 |
|------|------|----------|
| 美术资源不足 | 中 | 使用开源素材或购买资产包 |
| 敌人AI过于简单 | 低 | 保持简单，重点放在攻击反馈 |
| 内容量超期 | 高 | 严格控制每章内容，优先完成主线 |
| 性能问题 | 低 | 限制同屏敌人数量，使用对象池 |
