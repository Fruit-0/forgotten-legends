# 项目立项文档

## 基础信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 我在异世界的那些年 |
| 类型 | 2D俯视角动作RPG |
| 引擎 | Godot 4.6 + GDScript |
| 目标平台 | Windows PC |
| 目标分辨率 | 1920x1080，手绘故事书风格（柔和渐变，避免硬边像素） |
| 游戏时长 | 2小时 |
| 参考游戏 | 奈斯启示录（Necesse） |
| 叙事框架 | [被遗忘的传说](叙事框架.md) - 可独立替换的故事顶层设计 |

## 核心体验

**一句话描述**：一个现代大学生穿越到异世界，在探索与战斗中成长，最终明白平凡日常的可贵。

**叙事驱动**：游戏围绕"当时只道是平常"的主题展开，主角从"逃离日常"到"拥抱日常"的情感转变是核心体验。

**核心循环**：
```
探索地图 → 击败敌人/完成任务 → 获取装备/材料/技能点 → 变强 → 挑战Boss → 进入下一章 → 最终回家
```

## 游戏系统概要

### 主角设定

- **身份**：刚参加工作的中国大学生，现代社畜
- **穿越方式**：雨夜被黑洞吸入异世界
- **特殊能力**：全元素属性（水、火、风、土），初始均为1点，可成长
- **游戏化面板**：主角能看到等级、属性、技能等数值（体现现代人思维）
- **性格**：初期迷茫孤独，逐渐在异世界善意中理解"人间自有真情在"

### 战斗系统
- **类型**：即时动作（非回合制）
- **操作**：WASD移动，鼠标瞄准攻击，空格闪避
- **元素系统**：水/火/风/土四元素，主角拥有全属性，技能分系别
- **死亡惩罚**：无惩罚，在当前区域复活（游戏化体现）
- **存档**：随时存档（F5快速存档，F9快速读档）

### 成长系统
- **装备获取**：敌人掉落 + 材料合成 + 商店购买 + 任务奖励
- **技能学习**：消耗技能点解锁（技能点来自升级和任务）
- **属性提升**：随等级自动成长

### 经济系统
- **双货币**：
  - 金币：通用货币，用于商店购买
  - 材料：用于合成装备，分为普通/稀有/传说品质

### UI风格
- **主界面**：可融入现代元素（如手机界面风格），体现主角现代人身份
- **游戏化面板**：角色属性面板可见等级、HP/MP、四元素属性数值
- **菜单风格**：简洁清晰，带轻微科技感，与"游戏化异世界"设定呼应

### 情绪曲线设计

| 章节 | 情绪定位 | 核心体验 |
|------|----------|----------|
| 第一章 | 迷茫+新奇 | "这是哪？我该怎么办？" |
| 第二章 | 孤独+坚韧 | "只能靠自己了" |
| 第三章 | 成长+温暖 | "原来这里也有善良的人" |
| 终章 | 决战+释然 | "我可以回家了" |
| 结局 | 感动+共鸣 | "妈，我回来了" |

### 世界结构
- **章节式**：共3-4个章节，每个章节一张固定设计的小地图
- **地图规模**：每张地图预计5-10分钟探索时间
- **连接方式**：击败章节Boss后解锁下一章传送门

## 内容规划

### 章节设计

| 章节 | 主题 | 地图规模 | 敌人种类 | Boss |
|------|------|----------|----------|------|
| 第一章 | 森林外围 | 小型 | 2种 | 哥布林王 |
| 第二章 | 地下洞穴 | 中型 | 3种 | 巨型蜘蛛 |
| 第三章 | 古代遗迹 | 中型 | 4种 | 守护者 |
| 终章 | 深渊入口 | 小型 | 5种 | 深渊领主 |

### 装备规划

| 类型 | 数量 | 获取方式 |
|------|------|----------|
| 武器 | 8-10把 | 掉落/合成/购买 |
| 防具 | 3套 | 掉落/合成 |
| 饰品 | 4-5个 | 任务/隐藏宝箱 |

### 技能规划

| 类型 | 系别 | 数量 | 示例 |
|------|------|------|------|
| 主动技能 | 水系 | 2-3个 | 水箭、治愈之泉、冰盾 |
| 主动技能 | 火系 | 2-3个 | 火球、火焰爆发、灼热之刃 |
| 主动技能 | 风系 | 2-3个 | 风刃、疾风步、旋风 |
| 主动技能 | 土系 | 2-3个 | 岩石投掷、大地护甲、地震 |
| 被动技能 | 通用 | 6-8个 | 攻击力+10%、移动速度+15%、元素亲和 |

**特殊机制**: 主角拥有全元素属性，可自由搭配各系技能，体现"成长型穿越者"设定。

## 技术约束

- **最大同屏敌人**：不超过8个（保证性能）
- **输入方式**：键鼠（暂不支持手柄）
- **本地化**：仅简体中文（首期）
- **分辨率自适应**：支持16:9和16:10

## 风险评估

| 风险 | 等级 | 应对措施 |
|------|------|----------|
| 美术资源不足 | 中 | 使用开源素材或购买资产包 |
| 敌人AI过于简单 | 低 | 保持简单，重点放在攻击反馈 |
| 内容量超期 | 高 | 严格控制每章内容，优先完成主线 |
| 性能问题 | 低 | 限制同屏敌人数量，使用对象池 |
